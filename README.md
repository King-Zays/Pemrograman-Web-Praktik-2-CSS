## 🚀 Topik yang Dipelajari
1. **Dasar CSS**: Cara menghubungkan CSS dengan file HTML (External, Internal, Inline).
2. **Layouting**: Membuat struktur web klasik menggunakan elemen `<div>` dengan ID dan Class.
3. **Styling Properties**: Menggunakan properti margin, padding, warna, tipografi, dan border.
4. **Form Design**: Mengubah tampilan default input form menjadi lebih menarik dengan CSS.
